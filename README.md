# Plataforma Saúdes Raras

Plataforma web para o registro de informações sobre Doenças Raras no Brasil  

Idealizada pela Profa. Patricia Saldanha do Programa de Pós Graduação em Mídia e Cotidiano da Universidade Federal Fluminense (UFF) [1] e desenvolvida pelos estudantes do curso de Ciência da Computação da mesma universidade com o auxílio de pesquisadores do IBICT [2] 

A plataforma ainda está em desenvolvimento mas pode ser visualizada em: https://saudesraras.pro.br

É uma versão especializada da Plataforma [Civis][3] construída com [Python][4] utilizando o [Django Web Framework][5].
